# Portfolio Web · Galo Ginés García

Portfolio personal desarrollado para presentar mi perfil profesional, mi trayectoria, mis servicios, mis tecnologías principales y diferentes vías de contacto.  
La web está enfocada en transmitir una imagen moderna, técnica y visualmente cuidada, con una estética oscura, premium, dinámica y responsive.

---

## Descripción del proyecto

Esta página web funciona como portfolio profesional y carta de presentación digital.  
Su objetivo principal es mostrar de forma clara y atractiva:

- Quién soy.
- Mi trayectoria académica y profesional.
- Las tecnologías que utilizo.
- Los servicios que puedo ofrecer.
- Mi disponibilidad para proyectos o colaboraciones.
- Un formulario de contacto funcional.
- Un asistente virtual básico integrado en la propia web.

El diseño busca una estética visual oscura, elegante y tecnológica, usando efectos tipo glassmorphism, animaciones suaves, fondos con halos luminosos, tarjetas interactivas y transiciones modernas.

---

## Flujo de navegación de la web

La web está organizada en diferentes pantallas principales:

### 1. Inicio

La página principal introduce el portfolio con una presentación visual dinámica.  
Incluye una composición animada central con órbitas, un diseño oscuro con efectos luminosos y secciones de acceso rápido hacia las partes principales de la web.

Desde esta pantalla se puede acceder a:

- Biografía.
- Servicios.
- Tecnologías.
- Contacto.

Las secciones aparecen con animaciones laterales alternas al hacer scroll, aportando sensación de movimiento sin recargar la experiencia.

---

### 2. Biografía

La pantalla de biografía está dedicada a presentar mi trayectoria de una forma más personal y profesional.

Incluye:

- Resumen de perfil.
- Trayectoria académica.
- Objetivos profesionales.
- Sectores de interés.
- Botón de descarga del CV.

Esta sección incorpora animaciones al hacer scroll, una línea de progreso visual en la trayectoria académica y tarjetas con efecto cristal.  
El objetivo es que la información no aparezca de golpe, sino que se vaya revelando de forma progresiva y dinámica.

---

### 3. Servicios

La sección de servicios muestra las áreas en las que puedo aportar valor.

Está dividida en tres bloques principales:

- Desarrollo web.
- Aplicaciones.
- Colaboración técnica.

Cada tarjeta tiene un estilo glass premium con colores diferenciados:

- Desarrollo web: rojo.
- Aplicaciones: amarillo.
- Colaboración: verde.

Al pulsar en “Ver opciones”, se abre una ventana modal con más información sobre cada servicio.  
Esto permite mantener una interfaz limpia, pero con información ampliada disponible cuando el usuario la necesita.

---

### 4. Tecnologías

La pantalla de tecnologías presenta el stack técnico de forma visual e interactiva.

Incluye tecnologías como:

- HTML5.
- CSS3.
- JavaScript.
- PHP.
- Angular.
- Node.js.
- Java.
- Python.
- Flutter.
- C#.
- SQL.
- Go.
- XML.
- DTD.
- XSD.
- Git.
- Bitbucket.
- AWS.

Cada tarjeta tiene un color personalizado relacionado con la tecnología que representa.  
El diseño mantiene la estética glassmorphism de la web, con brillos, bordes luminosos, tarjetas interactivas y transiciones suaves.

---

### 5. Contacto

La pantalla de contacto permite que cualquier visitante pueda escribirme directamente desde la web.

Incluye:

- Formulario de contacto conectado con EmailJS.
- Canales de contacto directo.
- Enlaces a LinkedIn e Instagram.
- Bloque de disponibilidad.
- Sección de donaciones mediante PayPal.

El formulario envía los mensajes directamente al correo configurado mediante EmailJS.  
La sección está diseñada con tarjetas oscuras, efecto cristal, botones premium y animaciones de entrada.

---

### 6. Chatbot flotante

La web incluye un chatbot flotante en la parte inferior derecha.

Este asistente virtual funciona de forma local mediante JavaScript, sin necesidad de backend ni API externa.  
Responde automáticamente a preguntas relacionadas con:

- Servicios.
- Tecnologías.
- Contacto.
- CV.
- Biografía.
- Presupuesto.
- Disponibilidad.
- Donaciones.

El chatbot incluye:

- Botón flotante con icono de robot.
- Panel desplegable.
- Sugerencias rápidas.
- Respuestas automáticas.
- Enlaces directos a secciones de la web.
- Diseño integrado con la estética general del portfolio.

## Herramientas y tecnologías utilizadas

### Frontend

- HTML5.
- CSS3.
- JavaScript.
- Diseño responsive.
- Glassmorphism.
- Animaciones con CSS.
- Manipulación del DOM con JavaScript.

### Animaciones

- GSAP.
- ScrollTrigger.
- Transiciones al hacer scroll.
- Animaciones de entrada únicas.
- Efectos de aparición progresiva.
- Efectos hover en tarjetas y botones.

### Scroll suave

- Lenis.

Se utiliza para mejorar la experiencia de navegación y conseguir un desplazamiento más fluido en escritorio.

### Formulario de contacto

- EmailJS.

Permite enviar correos directamente desde el formulario sin necesidad de backend propio.

### Donaciones

- PayPal.

La pantalla de contacto incluye una sección preparada para realizar donaciones voluntarias.

### Publicación

- GitHub Pages.

El proyecto está pensado para funcionar como una web estática desplegada directamente desde GitHub.
